# Programación — 1º DAM

Repositorio de apoyo para el módulo **Programación (0485/0484 según plan de estudios)** de 1º de Desarrollo de Aplicaciones Multiplataforma.

El material está organizado de forma progresiva, desde los fundamentos de Java hasta programación orientada a objetos, colecciones y excepciones.

## Organización

1. `01-fundamentos` — sintaxis básica, variables, tipos, entrada/salida y operadores.
2. `02-condicionales` — estructuras `if`, `else` y `switch`.
3. `03-bucles` — `for`, `while`, `do-while`, contadores y acumuladores.
4. `04-arrays-strings` — arrays, matrices, cadenas, búsquedas y ordenación.
5. `05-poo` — clases, objetos, constructores, encapsulación y miembros estáticos.
6. `06-herencia-polimorfismo` — herencia, clases abstractas, interfaces y polimorfismo.
7. `07-colecciones` — `ArrayList`, iteradores y otras colecciones.
8. `08-excepciones` — tratamiento y creación de excepciones.
9. `09-proyectos` — ejercicios y proyectos integradores.

## Uso

Los ejemplos están pensados para acompañar las explicaciones de clase y servir como referencia para prácticas y ejercicios. El repositorio irá creciendo durante el curso.

> Los repositorios históricos se mantienen sin modificar. Este repositorio contiene una selección reorganizada del material docente.
