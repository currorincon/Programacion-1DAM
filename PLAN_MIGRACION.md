# Criterio de selección del material histórico

El nuevo repositorio se construye a partir de material docente existente, pero los repositorios originales permanecen intactos.

## Se incorpora

- Fundamentos de Java y entrada/salida.
- Condicionales y bucles.
- Arrays, matrices, algoritmos básicos y Strings.
- Programación orientada a objetos.
- Herencia, interfaces y polimorfismo.
- Colecciones.
- Excepciones.
- Proyectos integradores seleccionados.

## Se excluye

- Exámenes y soluciones de pruebas evaluables.
- JDBC, conexiones a bases de datos y el proyecto Aucorsa, que corresponden a Acceso a Datos.
- Metadatos de IDE (`.idea`, `.project`, `.classpath`, `.iml`, etc.).
- Ficheros del sistema como `.DS_Store`.

## Repositorios de origen

Los repositorios históricos no se modifican ni eliminan. Este repositorio es una selección limpia y reorganizada para 1º DAM.

## Resultado

Migración completada para revisión en `importacion-material`. Véase [el inventario de los 143 archivos incorporados](docs/MIGRACION.md) y [las limitaciones heredadas](docs/LIMITACIONES_DOCENTES.md). No se fusiona a `main` ni se elimina material anterior.
